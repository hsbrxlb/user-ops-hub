车主故事征集

OEDRO

OEDRO Garage Stories邀请车主分享真实产品使用细节，为其他车主提供实际经验参考，并在获得许可后供品牌复用。

Garage Stories现已开放，投稿截止时间为美国芝加哥时间（America/Chicago）2026年12月31日23:59。

加入 OEDRO Discord ↗ Garage Stories 投稿串 ↗ Garage Stories Help 私密协助 ↗

谁能参加

参与者须为美国居民，年满18岁（当地法定成年年龄更高的，以当地要求为准），已加入 OEDRO Discord，且实际使用过可辨认的 OEDRO 产品。优惠券适用于 OEDRO.com 支持配送的美国地址。

投稿无需为此重新购买产品。正面、中性和负面体验均可；好评、粉丝量、点赞、邀请人数和聊天活跃度不影响审核。

提交什么内容

拍摄新的 OEDRO 真实使用照片或视频；加入 Discord 后，在原 Garage Stories 投稿串提交作品链接，并附产品名称、使用时长和一项真实发现。车型资料可按内容需要补充。

比如安装时注意到的细节、用了一段时间后的磨损，或者哪里不满意。

投稿串是本活动唯一投稿入口。涉及隐私的材料，可先在串内登记投稿，再通过 Garage Stories Help 私密核对；私人账号无需设为公开。订单和个人资料请勿发在公开聊天中。

怎样算合格

  • 作品须来自作者真实使用 OEDRO 产品的经历，包含原创照片或视频，并附可理解的实际使用观察。用于品牌复用的版本须具备所需素材和人物许可。
  • 同一作品跨平台只算一次。裁剪、换文案、视频截图或同一作品的轮播图不额外计数；第二份须有明显不同的原创素材和使用信息。
  • 搬运内容、编造或合成的使用经历、员工投稿和测试账号不计入奖励。

奖励怎么拿

每件合格且独立的作品奖励一张20美元优惠券，共20份，每人最多两份。名额按投稿资料与具体品牌复用许可全部齐备的时间排序；预留真实码后，方确认奖励名额。

  1. 在 Garage Stories 投稿串提交作品与使用信息。
  2. 内容经人工审核；需要补充材料时，说明具体缺项。
  3. 单独确认该作品的品牌复用许可，再确认奖励名额。
  4. 经 Garage Stories Help 私密发送投稿专属优惠券。

完整投稿的审核目标为3个工作日；确认名额并记录具体许可后，预留给该投稿的优惠码目标在2个工作日内私密交付。工作日指周一至周五。名额用完后将在投稿串更新；疑问或复核请求同样通过 Help 处理。

每张券适用于符合条件的商品合计满21美元减20美元，税费和运费不计入门槛；本券没有额外商品或品类排除。每个码只能成功使用一次，一笔订单使用一个码；领到两张须分两单使用。

不可与其他优惠码或活动折扣叠加，包括满减、满件、闪购、组合和预售优惠。所有码统一有效期：美国中部时间（America/Chicago）2026年10月8日00:00至2027年1月31日23:59:59；晚领取不会延长有效期。

会员入群优惠与投稿奖励独立。仅入群不获得投稿奖励，也不从入群券库存中发放；两种券不能在同一订单叠加。

品牌复用许可

提交链接不等于授权品牌使用。审核后会逐件私下说明拟使用的官方渠道、允许编辑的范围和使用期限，并由创作者明确同意；版权仍归创作者，超出已记录许可的用途需另行同意。

可以不授权而在社群分享，但本轮投稿奖励须具备具体复用许可。私人作品须明确同意后才公开使用；合格不保证被品牌展示，复用须保留原意，包括批评。

可通过同一个 Help 私聊询问或撤回许可；收到撤回后停止新的使用，并说明已有品牌副本如何处理。已发出的奖励不会因负面意见或合理撤回而收回。材料按现有隐私政策用于活动运营；请勿发送密码或身份证件。

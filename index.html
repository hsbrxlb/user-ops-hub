OEDRO 和 Cozeware

OEDRO

面向皮卡和越野车的车用配件品牌。内容围绕安装、装载和实际用车中的具体问题，语气像懂车、可靠的车库搭档，带一点冷幽默。

OEDRO 品牌口吻

Cozeware

关注家庭冷暖、通风和房间的实际使用，口吻细心、温和，带一点小幽默。FreshFlow 是把经过过滤的室外空气引入房间的新风设备。

Cozeware 品牌口吻

每天的工作

  1. 按品牌内容指南和排期定选题、目的和平台。
  2. 先写剧本并审核，再做图片或视频、配文案，最后质检。
  3. 完整图文负责人过审后，交给两位印尼运营同事 按日期、按平台发布。
  4. 在排期表里记下发布链接和效果，顺便补充内容素材库。

OEDRO 和 Cozeware的社媒内容
图文和视频按品牌分别准备。OEDRO 围绕真实用车、安装和装载，Cozeware 围绕冷暖与通风。
FreshFlow 内容
按协同排期每周发布 3 条。首批 3 条讲清“净化不等于换气”，写实产品图用真实照片和实验画面。
Discord 社区
欢迎新成员，回复安装和使用问题，整理用户反馈。轻松漫画用于社区每日内容。
用户调研问卷
调研围绕新风机使用场景和工作灯使用体验。
老客邮件
OEDRO 的 The Glovebox 提供实用用车内容，Cozeware 的 Room Notes 提供居家内容。
积分与用户活动
按品牌查看积分规则、故事征集和抽奖。
红人引流
通过合作创作者的视频说明栏，把观众引到各品牌的 Discord 社区。
OEDRO 官网 Discord 入口
首页有桌面和手机两套轮播。购物车的 Discord 入口已列入开发需求。

# Cozeware-新品

介绍新产品，引导读者查看产品详情和安装适配；样例用 FreshFlow。

| 顺序 | 内容与替换位置 |
|---|---|
| 收件箱 | `<title>` 主题、隐藏预览句、平台发件人 |
| 头部 | 满宽主图和替代文字，Cozeware Logo 与官网导航 |
| 正文 | H1 → 导语 → 主按钮 → 两块短说明 |
| 主按钮 | 活文字与目标 URL `{{product_url}}` |
| 页脚 | 已核实的品牌信息、`{{mailing_address}}`、动态退订 `{{ unsubscribe_url }}`、政策与社媒 |

**本次替换位**　产品名、经核产品要点、真实产品图、在用产品页面和对应安装指南。

## 版式

600px 桌面宽，390px 手机看样，正文边距 24px／16px，正文 Helvetica 或 Arial 16/24px，标题 Georgia 或 Times New Roman 35/40px／29/33px。主图桌面 600 × 375px，贴满邮件顶边。外底 `#ECD8C5`，内容底 `#FFFAF2`，标题 `#422C23`，正文 `#443228`，页脚 `#F4E7D6`，辅助块 `#F7E7D5`。模块圆角 16px，主图顶角 18px，陶土色按钮 `#903B26`、52px 高、999px 圆角，阴影 `0 5px 14px rgba(115,55,29,.19)`。

# Cozeware-弃单提醒

在经核实的购物车保存但未购买情形下，提醒有营销许可的收件人回购物车。

| 顺序 | 内容与替换位置 |
|---|---|
| 收件箱 | `<title>` 主题、隐藏预览句、平台发件人 |
| 头部 | 满宽主图和替代文字，Cozeware Logo 与官网导航 |
| 正文 | H1 → 导语 → 主按钮 → 两块短说明 |
| 购物车商品 | `{{cart_item_name}}`，显示购物车实际商品 |
| 主按钮 | 活文字与目标 URL `{{cart_url}}` |
| 页脚 | 已核实的品牌信息、`{{mailing_address}}`、动态退订 `{{ unsubscribe_url }}`、政策与社媒 |

**本次替换位**　购物车恢复 URL、`{{cart_item_name}}`、触发延迟与下单后停止规则。

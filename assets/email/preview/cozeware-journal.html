Measure your window first

Window-mounted units are built around the clear opening, so measuring it first shows what size and install guide will actually suit your window.

Two checks to try

1. Measure the opening

With the window open, use a tape measure to check the clear width and height inside the frame.

2. Look for obstructions

Check sash travel, screen and trim, then compare your dimensions and window type with the model-specific installation guide.

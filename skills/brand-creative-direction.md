# 品牌创意方向

给目标读者一个停下来的理由。事实准确、语法整齐、画面清晰都是必要检查，但它们不是创意。

## 什么时候用

- 品牌社媒文案和活动图片，尤其是“产品很普通、写出来很平”的情况。
- 稿件被退回，说“太泛”“像谁都能发”“没意思”。

不用于客服回复、法律文本和常规界面文案；这些清楚完整优先。

## 工作顺序

1. **还原任务。** 实际读者、目的、事实、品牌依据、谁在说话、希望读者有什么反应。把已确认的品牌资产与“提议”分开。自己整理一份简短创意简报，不让需求方填表。
2. **比较两三个真正不同的想法。** 每个想法要有：一个观察、一个创意机制、一份读者回报、与品牌／产品的联系、图文各自承担什么。只换形容词、配色或叙述者不算另一个想法。
3. **选一个方向。** 按上面几项选；句式、字数、道具数量、CTA 和媒介跟着任务走，不由它们决定想法。
4. **分两道关审实际成品。** 真实与权限一道，创意强度一道。每个判断都指出具体句子、画面关系或缺失。
5. **失败就换前提。** 先换掉底层想法，再打磨；被退回的版本标注为反例保留。

## 写之前要回答的问题

- 谁在什么情境下看到它？为什么那一刻在乎？
- 希望读者感到、理解、记住或做什么？（不一定需要明确的 CTA）
- 素材来自什么具体观察、矛盾、阻碍、有用发现或人的愿望？
- 说话者能如实宣称什么？是品牌发言、真实用户、假设情境还是明显的虚构？
- 图片提供了文字没有的什么，反过来呢？
- 什么情况下它即使准确、好看也会失败？

## 创意机制（可选，不是清单）

观察到的矛盾、人物相互冲突的愿望、逐步升级的后果、延迟兑现的回报、意外但相关的类比、意外有用的发现、一个物件获得新的角色。

每个候选都要有具体的读者回报：被认出来、被逗笑、好奇心被兑现、看懂一个情感瞬间、得到一个有用的区分或答案。“一个泛泛的问题 + 一个产品功能”不算回报。

## 语气与虚构

- 允许口语、缩写、短句、停顿和长短句变化；不要机械改成公司腔。
- 不制造错别字和破句来装“像人”。
- 明显虚构的叙述可以用，但不能伪装成创始人、员工或真实用户证言。
- 夸张的情绪可以，编造的产品效果、背书和性能不行。
- 不照搬别家品牌的怪癖和姿态，借鉴的是让它成立的方法。

## 图文关系

遮住标题，画面本身要提供相关素材：一个具体场景、关系、演示、情绪节拍、有用细节或有目的的视觉笑话。孤零零的物件、米色纸张、稀疏字体和好看的质感不是默认品牌方向。遮住画面，文字要补充观点或信息，而不是复述画面里的东西。

## 图片简报（出图前填完）

| 决定 | 需要写清的内容 |
| --- | --- |
| 传达任务 | 读者情境、期望反应、一个具体收获 |
| 创意想法 | 看得见的关系、事件或张力；观众得到什么 |
| 品牌锚点 | 已批准的品牌素材与口吻；未批准的标为提议 |
| 图文分工 | 各自承担什么，图内精确文字，阅读顺序 |
| 媒介 | 照片、参考图编辑、对比、标注细节、图解或字体海报；精确标签用可靠排版，不让模型编 |
| 场景与动作 | 在哪、发生什么、关键物件和关系 |
| 参考图 | 具体文件及各自角色：产品真实、标识、构图、材质光线、语气 |
| 不变项 | 必须保留、可以变化、现实中最可能出的错 |
| 交付 | 渠道、比例、尺寸、可读性、裁切、格式、体积 |
| 验收 | 具体的内容／品牌失败点，加技术检查 |

负面指令只用来保护真实的不变项或防止已观察到的失败。不要把参考例子里的“无 Logo”“极简”自动带进所有提示词。

## 两道审查

**真实与权限：** 字面和隐含的说法、说话人、证据、产品身份、参考、授权、披露、翻译、行动路径。创意再好也不能抵消这里的失败。

**创意：** 对照读者任务，给出具体证据：

1. 注意力与回报：凭什么继续看，回报在哪？
2. 具体性：哪个观察、事件或关系让它不是泛泛的广告？
3. 品牌联系：为什么属于这个品牌？只有 Logo 不算。
4. 执行：口吻、画面和信息是否支持同一个想法，又不互相重复？

任何一项实质失败就退回，并给出想法层面的修法；缺少真实执行所需的材料就标“需要输入”。不要把失败平均进总分。

## 审稿卫生

- 独立评审时隐藏作者、模型、旧分数和自我评价。
- 第二个模型同意不等于受众认可。
- 人工否决优先于此前的 AI 评估；保留旧版、具体原因和新假设。

## 结论格式

只用三种：`可交人工审阅`、`退回修改`、`需要输入`，并写明实质原因。结果是候选，不是吸引力或表现的证明。

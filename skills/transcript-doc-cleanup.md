# 转写与杂乱文档清理

在保留源证据的前提下，产出更干净的工作文本。不要把不确定的转写修正直接当成定论。

## 什么时候用

- “清理一下访谈／会议的转写”。
- 从聊天导出、OCR、杂乱的 DOCX／PDF／PPTX 里提取内容并保留证据。
- 修中英混杂、识别错误多的记录。

不用于普通的 Word／PDF／PPT 排版，也不用于已经整理好的文档。

## 步骤

1. **识别来源类型：** 语音转写文本、DOCX、PDF、PPTX、聊天导出、图片，或混合。
2. **先用现成的文档工具：** 版式重要时用能渲染页面的工具提取，不要只抓纯文本。
3. **保守地修正转写错误：**
   - 保留人名、产品术语、时间戳和不确定标记；
   - 听不清、认不准的地方标出来，不编造措辞；
   - 在工作笔记里记下来源路径和提取方法。
4. **按主题整理，而不是按文件名。** 原始文件先归档保留，再清空收件箱。

## 质量检查

- 版式重要时，实际渲染或目视检查 PDF／DOCX／PPTX。
- 把清理后的文本和源片段逐项比对：人名、日期、价格、决定、行动项。
- 不确定的说法留在摘要或审计层，不升级为正式结论，除非需求方要求。
- 给他人看的长文，按正常的成文标准再过一遍。

## 标注约定（示例）

```text
[听不清 00:12:31]
[疑似：“适配”／“匹配”，00:14:02]
[原文：……] → [整理：……]
来源：会议录音转写 第 3 段；提取方式：自动转写 + 人工校对
```

## 第三方工具

社区里的转写修正、文档转 Markdown 工具可以参考思路。运行它们的脚本或安装依赖之前，先审查写入路径、安装的包、是否需要密钥、清理行为。

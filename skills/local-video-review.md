# 本地视频审看

不播放声音，用抽帧和联系表把一段视频“看”完，再给出带时间点的意见。

## 什么时候用

- 审看红人视频、广告素材、产品演示或自己剪的样片。
- 需要指出“第几秒有什么问题”，或核对画面里的字、产品和动作。

## 做法

1. **抽总览帧。** 用 FFmpeg 按固定间隔抽帧，总数控制在约 150 张以内，每 9 张拼成一张 3×3 的联系表，每格标上时间码。同时保存帧清单（时间码 → 文件）。
2. **先看联系表。** 快速把握结构：开场钩子、场景切换、产品出现的位置、结尾。
3. **再看原帧。** 小字、商标、产品细节、手部动作，回到对应的原尺寸帧去看。
4. **需要精确数字时，** 按每秒一帧、原始宽度抽帧，逐帧核对。注意这些是“名义时间”，精确的剪辑点要回到源视频确认。
5. **需要镜头切换点时，** 用场景检测找出真实的切换时间，而不是靠均匀抽帧猜。
6. **写意见。** 每条意见带时间码、看到了什么、为什么是问题、建议怎么改。

## 常用命令

```bash
# 每 2 秒抽一帧，缩到 480 宽
ffmpeg -nostdin -i input.mp4 -vf "fps=1/2,scale=480:-1" frames/%04d.jpg

# 拼成 3×3 联系表
ffmpeg -nostdin -i frames/%04d.jpg -vf "tile=3x3" sheets/sheet_%03d.jpg
```

## 提醒

- 抽帧成功不等于看过了。要真的逐张看联系表和关键原帧。
- 输出最后一帧是近似的结尾帧。
- 只看了字幕、没看画面，就写“只看了字幕”；没看就不下结论。
- 全程静音：不播放、不外放。
- 抽出来的重复帧是过程文件，任务结束后清理；原始素材和必要证据保留。
- 网上的视频，只在已授权的环境里获取。

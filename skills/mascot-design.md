# 品牌吉祥物设计

让角色值得被喜欢，也能在下一张图里被认出来。零件来源、漂亮材质和长提示词，都不能代替这两件事。

## 什么时候用

- 为品牌新设计吉祥物，或修改已有角色。
- 收到“不讨喜”“太像机器”“人形比例吓人”这类反馈。
- 要把一个已接受的角色扩展成多视角、多动作的一组图。

不适用于普通 Logo、通用插画或界面设计。

## 先接清楚需求

记录：品牌、服务对象、使用场景、已有标识、期望性格、明确不想要的感觉、交付文件、发布范围。未知事实保持未知，不替品牌编故事。只有会改变方向的缺口才追问。

每次任务保留一张简短工作单：品牌事实、当前有效要求、已被新要求替代的旧要求、本次改什么、保持什么、怎么验收。不要把互相矛盾的历次反馈全部塞进提示词。

## 01 先选角色感，再选零件

拟人程度是一条连续的尺度：普通器械 → 带情绪的零件 → 短肢体伙伴 → 完整人形。先确定这次需要哪一段。觉得“太器械”时，先加清楚的视线、眉眼变化和有目的的动作，不必同时加人类长腿、手掌、衣裤和鞋。

每个方向说清三件事：它为什么属于这个品牌；哪一个轮廓能让人记住；它怎样表达关注和帮助。

画风与角色身份分开选。借鉴成熟作品如何组织轮廓、表情和姿态，不复制已有角色的标志性组合。

## 02 先画一个，再扩成一组

先生成一个完整角色。看它有没有明确的注意力和意图、是否亲近、轮廓能否记住、零件是否真正连接。

- 问题是“没有性格”：先改脸和动作。
- 问题是“比例吓人”：先改骨架。
- 不要用更多螺丝、反光和材质掩盖方向错误。

主图通过后冻结身份说明：身体比例、主轮廓、眼睛与表情位置、肢体数量、关节位置、材料分工、颜色面积、识别特征、字标位置。后续图都以这张主图为参考。

默认一组四张独立大图：完整形象、侧后关系、实际使用场景、动作瞬间。四张要有不同视角与动作，而不是四种角色站在同一个角度。

## 03 把一致性写进记录

每张图记录：角色编号、版本、视角、源图、参考图、完整提示词、生成方式、审查结果。提示词顺序：用途与角色意图 → 身份说明 → 这一张的姿态和镜头 → 结构接触关系 → 材料与颜色 → 字标位置 → 背景构图 → 明确禁项。每条完整独立，不写“同上”。

字标依附真实表面（背带织标、铭牌等），随透视转向；没有正式商标源文件时只做位置探索，不伪造官方 Logo。

## 04 一张一张检查

先看角色感，再看结构、身份一致、动作接触、字标和颜色：

- 眼神是否落在目标上，手或夹爪是否真的连着身体，脚是否承重。
- 道具是否穿模，转身后是否凭空多出零件。
- 对照主图，而不是只看单张漂亮不漂亮。
- 再看原尺寸、64px、32px、灰度、轮廓，以及浅深背景下的效果。

不合格只改对应图片和问题，保存原图与诊断，不覆盖唯一来源。

## 05 按交付媒介展示

每张图有独立的大图位置；总览拼图只是补充。说明文字用自然的动作短语，不展示提示词里的制作术语。没有明确需要时，不加筛选、折叠、候选或淘汰标签。

## 收到新反馈时

先把反馈归类：角色感、比例、表情、画风、配色、字标、动作、一致性或展示方式。写明改变哪一项、保留哪几项，再做一张验证。新的明确要求优先，历史要求保留在修订记录里。

## 换一个品牌时

重新确认品牌事实、受众、场景和情绪。上一个品牌的配色、比例和性格不是所有品牌的规定。

发起模板：

> 为【品牌】设计吉祥物，用于【场景】，希望像【性格】，不希望像【反例】；保留【已有特点】，改变【不满意点】。先做一张主图，通过后扩展【视角与动作】。

## 从探索中留下的经验

| 出现的问题 | 可复用的做法 |
| --- | --- |
| 机器人很通用、动物拿工具不自然 | 先审骨架与气质，工具不能替代身份 |
| 多个方向都被同一组颜色覆盖，像同一型号 | 先分配材料与色块职责，再比较配色 |
| 零件角色太器械 | 加可读的注意力与有意图的动作，不急着加人类长腿 |
| 新角色总用同一个角度站着 | 先固定身份，再画侧后、工作和动作 |
| 动物长腿直立，像兽头人身 | 回到紧凑自然骨架，拟人靠表情和意图 |
| 背面像正面镜像、零件数量变化 | 逐项核对拓扑、数量、接触和可见面 |
| 超长提示词仍出没有性格的器械 | 字数不是质量指标，主图关口更重要 |

## 检查清单

- [ ] 品牌事实有来源，未知事实没有被补成故事。
- [ ] 新旧要求分清，拟人程度、角色意图和场景明确。
- [ ] 主图先通过视觉审查，再作为后续参考。
- [ ] 一组一个身份；身体、表情位置、关节、材料一致。
- [ ] 不同画面有不同镜头和真实动作，接触与支撑成立。
- [ ] 字标拼写、次数、位置正确。
- [ ] 小尺寸、灰度、轮廓检查指向具体的那张图。
- [ ] 人工结论与自动检查分开，不冒充用户测试或商标结论。
- [ ] 只重做失败项，历史图保留。

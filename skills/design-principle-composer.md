# 设计原则配方

先选原则，再做设计。它定方向和约束，具体实现交给各媒介的制作流程。

## 什么时候用

- “别套模板，给我一套原创视觉方向。”
- 要统一一个网站、一套 PPT、一组图片或视频的设计系统。
- 开放式视觉任务，开工前需要能追溯来源的原则。

不适用：很小的视觉修改、要求精确还原某个参考、方向已经锁定的工作。

## 第一步：给需求分类

写清媒介、受众、任务、信息密度、想要的气质、文化语境、制作限制和已有的品牌约束。工具型产品，功能和工作界面优先于视觉冲击。

## 第二步：选三个角色

| 角色 | 负责什么 |
| --- | --- |
| 主锚点 | 结构、层级、空间秩序或叙事骨架 |
| 辅助 | 强化另一个变量：材质、节奏、可读性或感官气质 |
| 对位（可选） | 引入一个受控的张力，不改变锚点 |

默认只用两个原则。只有需求真的受益于张力、作品也有空间表达时，才加对位。

## 第三步：检查冲突

- 两个原则对同一个控制变量开出不同处方，拒绝。
- 把某种文化语境当装饰，拒绝。
- 只因为名字听起来高级而选，拒绝。
- 固定 IP 的角色、轮廓和身份规则高于配方。
- 多页面或多场景作品全程用一套配方，各页只调强度，不换血统。

## 第四步：把名字翻译成决定

开工前，配方必须写明：网格、尺度、节奏、密度、边界、材质、图像语言、动效、排除项。对外文案和生成提示词里写的是这些决定，不写人名。

各媒介还要补充：

- **网页／应用：** 首屏让用户能做什么、哪个元素主导、哪些刻意安静。工具界面从工作区开始，避免活动式大标题、假设备框、装饰性 AI 插图，以及只是把一个列表切成方块的卡片。动效只用于定位、状态变化和连续性。
- **PPT：** 故事推进、页间节奏、演示距离下的可读性。
- **图片／插画：** 主体、取景、空间逻辑、材质和光线。
- **视频：** 镜头节奏、转场目的、文字安全区。

## 原则卡示例

每张原则卡记录：出处、地区与年代、适用学科、控制的变量、兼容与冲突的卡、文化风险、版权边界。

| 原则 | 控制的变量 | 适合 |
| --- | --- | --- |
| 有用而诚实 | 功能、克制 | 工具界面、品牌、PPT |
| 内容层级 | 层级、字体 | 阅读页、报告 |
| 网格客观性 | 网格、秩序 | 网页、海报 |
| 系统纪律 | 系统、一致性 | 多页面品牌系统 |
| 间（日本美学中的“間”） | 留白、节奏 | 安静的阅读与品牌页 |
| 被服务与服务空间 | 主次空间 | 工具界面的信息架构 |
| 颜色关系 | 色彩相互作用 | 配色系统 |
| 压缩隐喻 | 符号、隐喻 | 海报、片头 |

## 边界

- 借鉴可迁移的原则，不模仿表面风格。
- 对在世创作者，永远不要求“用某人的风格”生成作品。
- 保留每张传统文化卡记录的地区、年代、媒介和文化限制。传统文化卡默认不参与自动挑选，只有需求与该文化、地区、材料实践或合作确有关系时才用。
- 不把不同传统笼统归成“非洲风”“中国风”“亚洲美学”。
- “来源已核实”和“已在本地验证有效”是两件事。
- 配方默认留在内部，需求方要求时才展示。

## 交付前

按目标尺寸看实际成品，读完所有小字、标签、图注和交互状态；完成后再走一遍视觉审查。
